# Política de seguridad

No publiques `.env`, `.env.chatbot`, claves de API, tokens de sincronización, credenciales MQTT ni bases de datos con lecturas reales. El dashboard y la API están pensados para acceso local o mediante un túnel SSH; revisa autenticación y red antes de exponerlos a Internet.

Si encuentras una vulnerabilidad, usa **Report a vulnerability** en la pestaña Security de GitHub si está disponible. En caso contrario, contacta al mantenedor en privado a través de su perfil. No incluyas credenciales ni datos de sensores en issues públicos.
